从今天起,KnowWhy 不再只是一个网站,它也是一个公开的、可以被完整翻阅的工程。

站点的全部源代码已在 GitHub 正式公开:

**仓库地址:[https://github.com/zyhgov/KnowWhy](https://github.com/zyhgov/KnowWhy)**

## 为什么要开源

KnowWhy 的信条是「知其然,更要知其所以然」——对文章里的每一个问题如此,对这个站点本身也应该如此。

以前,你只能看到我们写下的答案;现在,你可以看到这些答案是**怎么被写出来、怎么被组织、怎么被渲染成页面**的全过程:

- **内容可追溯**:每一篇 WHY、Know 与新闻的源文件都在仓库里,和你在页面上读到的一一对应;
- **工程可复现**:整站基于 Astro 构建,如果你想做一个类似的站点,这里有一份真实运行中的参考实现;
- **审查更彻底**:如果某篇文章有事实错误,或者页面有奇怪的 bug,你可以直接翻开源码,找到问题出在哪一行。

换句话说:**开源让「知其所以然」从一句内容主张,变成了这个站点本身的属性。**

## 仓库里有什么

- 站点的全部工程代码,包括页面、组件与样式;
- 所有已发布文章的 Markdown / MDX 源文件,包含你正在读的这一篇;
- 内容集合的 schema 定义与构建配置。

## 如何参与

- 发现内容错误、渲染问题或代码缺陷:欢迎到仓库提交 Issue;
- 有更好的实现思路:欢迎提交 Pull Request;
- 想推荐一个值得追问的「为什么」,或想指出内容问题:仍然可以发邮件到 [info@zyhorg.cn](mailto:info@zyhorg.cn)。

如果这个站点曾帮你弄明白过一件小事,顺手给仓库点一颗 Star,就是对我们最好的鼓励。

## 最后

写第一篇文章的时候,我们说过:要把生活里那些脱口而出的「为什么」,认认真真记录下来。现在,我们把记录这些「为什么」的工具也一并交了出来。

把做过的事情摊开,让它经得起看——这大概就是「知其所以然」在开源社区的写法。

愿每一次追问,都让你更靠近世界的真相。
